В моей базе данных содержатся данные ассирийского онлайн-словаря, где вдобавок к стандартным частям словаря содержится также аудиоозвучка каждого слова. Часть данных в моей БД я придумала сама, а часть данных была взята из словаря. На данный момент этот словарь опубликован на github pages, поэтому базу данных к нему подключить невозможно и все данные хранятся в файле xlsx. Но когда-нибудь, когда начнется процесс создания полноценного сайта онлайн-словаря, который можно выложить на сервер, словарю понадобится база данных.

Данные словаря устроены следующим образом: одна лемма словаря может делиться на несколько омонимов. В свою очередь, омонимы могут иметь несколько значений (т.е. обладать многозначностью, полисемией) - на сайте словаря такие значения в столбце meaning разделяются с помощью знака ";".

Также хочу обратить внимание на небольшие изменения. В первой версии я считала, что полисемичные значения могут делиться еще на несколько синонимов - на сайте словаря такие значения в столбце meaning пишутся через запятую. Поэтому изначальная версия БД выглядела так:
