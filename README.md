# Лабораторная работа

Лабораторная работа будет посвящена комплексной отработке навыков, которые мы получили на курсе по реляционным базам данных.

Задание заключается в том, чтобы разработать базу данных из домашнего задания 1.

## Критерии

### Базовое оформление
Сдать нужно один файл `lab.sql`. Файл лабораторной работы, названный иным способом, к проверке не принимается.

Скрипты должны быть разделены с помощью `;` (если не предусмотрены иные действия с БД, которые требуют другого разделителя). Старайтесь придерживаться хотя бы минимальной чистоты кода: один и тот же регистр для ключевых слов и названий таблиц, соблюдайте отступы. [Здесь](https://sql-ex.ru/blogs/?/Kak_pravilno_formatirovat_kod_SQL.html) отличный код стайл.

Код дополните комментариями, какой запрос какому заданию соответствует. Например,
```
-- Код к заданию 1

SELECT id
FROM Employee;
```

Все комментарии по заданиям вписывайте в скрипт с помощью однострочных или многострочных комментариев SQL.

### Оформление со звёздочкой (1 балл)
За дополнительный балл можно оформить код следующим образом: тетрадка `lab.ipynb`, подключение к MySQL с помощью Python-коннектора и совершение каких-то действий с помощью курсора. Требования к код стайлу SQL сохраняются. Требование к код стайлу Python примерно то же -- читаемость, ориентируйтесь на то, чему вас учили на прошлых курсах. Комментарии пишите в соответствии с задачей: либо комментарии к коду, либо какие-то иные комментарии в markdown (например, номер задания). Тетрадка должна легко воспроизводиться -- я запускаю, ничего не ломается.

### Описание (2 балла)
Задание заключается в следующем:
* В файле `description.md` описываете ваш проект: про что база данных, для чего может быть использована.
* Берёте схему, которую рисовали в ДЗ1. Если она большая, можно сократить до нескольких таблиц, таким образом оставив только нужные и важные. Основное остаётся неизменным: минимум 3 таблицы.
* В схеме должны быть указаны: таблицы, виды связей, ограничения, атрибуты, типы данных. База данных должна по максимуму отвечать 3НФ.
* Если я писала какие-то комментарии к вашей работе после ДЗ1, их нужно учесть. Например, если были не полностью указаны связи или связи были неправильные, то это нужно исправить. Если вы что-то забыли по этой теме, в первую очередь вернитесь к презентации. Если не понятно, что я имела в виду в комментарии, зайдите ко мне с вопросами. Если комментарии учтены не будут, оценка будет снижена.
* Есть шанс, что Вам придётся доработать свою базу данных, например, добавить новые атрибуты или даже таблицы. Вернитесь к этому заданию, когда дойдёте до последних критериев.

### Запросы (2 балла)
* Напишите 2 относительно сложных аналитических запроса по данным из вашей БД (за каждый 1 балл). По сложности ориентируйтесь на последние задания из ДЗ2: джойны, агрегации, группировки, оконные функции и т.д. Не стесняйтесь использовать и другие функции, которые мы проходили в рамках курса, если они применимы. Запросы должны быть осмысленные. (Возможно, здесь стоит вернуться к заданию 1...)

### Программирование (2 балла)
По данным из вашей БД напишите:
* пользовательскую процедуру и пример её вызова,

Запросы должны быть осмысленные.

#### Ремарка об оформлении routines
В MySQL есть некоторые особенности оформления routines, которые возможно понадобится применить.

### `DELIMITER`
Первая особенность заключается в том, что MySQL может путать окончания инструкций и программных процедур. Для того, чтобы не возникало ошибок, необходимо в начале процедуры или функции прописать инструкцию `DELIMITER` и обозначить, каким разделителем будет она будет оканчиваться.

``` sql
DELIMITER $$
```

Почитать: https://stackoverflow.com/questions/10259504/delimiters-in-mysql

### `DETERMINISTIC`
Данная инструкция говорит о том, что функция, запущенная с определённым параметром, будет каждый раз в одних и тех же условиях возвращать одно и то же значение. Этот параметр необходимо прописать после инструкции `RETURNS datatype`

``` sql
RETURNS datatype DETERMINISTIC
```
