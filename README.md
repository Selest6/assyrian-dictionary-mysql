# Assyrian Dictionary (MySQL)

Реляционная база данных ассирийского онлайн-словаря: леммы с омонимами, значениями и аудиозаписями.

Сейчас словарь живёт на GitHub Pages, данные лежат в Excel. Эта БД — схема бэкенда на случай, если словарь переедет на полноценный сайт. Часть записей взята из словаря, часть — тестовая.

## Схема

Одна лемма может иметь несколько омонимов (`homonym_number`). У омонима — несколько значений (полисемия). К лемме привязаны аудиозаписи и дикторы.

| Таблица | Что хранит |
|---|---|
| `Lemma` | Лемма, номер омонима, часть речи, морфология, этимология, диалект |
| `Meaning_polysemy` | Значения и примеры |
| `Speaker` | Диктор: имя, пол, дата рождения, локация |
| `Audio` | Путь к файлу, дата записи, связь с леммой и диктором |

Связи: `Lemma` 1—* `Meaning_polysemy`, `Lemma` 1—* `Audio`, `Speaker` 1—* `Audio`. Уникальность леммы: `(lemma, homonym_number)`.

## Что сделано

- DDL: создание БД `lexicon` (utf8mb4) и таблиц с внешними ключами
- DML: тестовые леммы, значения, дикторы и аудио
- Аналитический SQL:
  - топ-10 лемм по числу записей: сколько аудио, сколько разных дикторов, дата последней записи
  - для каждого диктора топ-2 самых часто записываемых лемм (оконные функции)
- Процедура `add_new_audio` — добавить запись и вернуть `id`
- Функция `get_lemma_recording_count` — число аудио у леммы
